# Lyric font

Noto Serif JP, regular weight, distributed under the SIL Open Font License in `OFL.txt`.
The WOFF2 files are unmodified Google Fonts subsets. The CSS family alias is `Lyric Serif JP`.
Unicode ranges let the browser load only the subsets needed for the displayed text.
The player serves the font files from its own static directory.

Source: https://github.com/google/fonts/tree/main/ofl/notoserifjp
CSS: https://fonts.googleapis.com/css2?family=Noto+Serif+JP:wght@400&display=block
Retrieved: 2026-10-20.
